Building blocks & cell lines,
one working list.

Reagent and cell-line stock for the LNP delivery programs, read live from the lab's shared Google Sheets. Nothing to install — open a sheet, edit a row, and it shows up here.

Keeping it current

Every record lives in a Google Sheet. Edit a row directly — keep the header row intact, one entry per row — and reload this app; it re-reads the sheets about once a minute.

Chemical sheet ↗ Cell sheet ↗
Chemical reads  name · cas · qty · vendor · position · cat · box · smiles
Cells read  cell line · atcc cat. no. · organism / background · tissue / disease · key feature or marker · recommended base medium · role in project · qty · unit price · line total

Extra columns are ignored, so side notes are safe. Blank SMILES cells get filled from the CAS number where possible — give those structures a second look.
