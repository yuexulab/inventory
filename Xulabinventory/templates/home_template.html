Xulab Inventory

Live view of the lab's chemical building blocks and ATCC cell lines. The data is read straight from shared Google Sheets, so anyone in the lab can keep it current without touching code — edits show up here within about a minute, or immediately on reload.

Updating the inventory

All records live in Google Sheets. To add, remove, or correct an entry:

  1. Open the relevant sheet: Chemical  /  Cells.
  2. Edit rows directly. Keep the header row intact and one record per row.
  3. Return here and reload — the app re-reads the sheets every 60 seconds.

Columns the app reads

Chemical: name · cas · qty · vendor · position · cat · box · smiles
Cells: cell line · atcc cat. no. · organism / background · tissue / disease · key feature or marker · recommended base medium · role in project · qty · unit price · line total

Other columns are ignored, so extra notes are fine. Blank SMILES cells are auto-filled from the CAS number where possible — worth double-checking those structures.
