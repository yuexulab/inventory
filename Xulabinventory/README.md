# Inventory Management System

A web-based application built with Flask for tracking and managing laboratory chemicals, reagents, and safety datasheets.

## Features

* **Inventory Tracking:** Log, update, and search chemical reagents currently stocked in the lab.
* **Flask Backend (`app.py`):** Lightweight and fast backend handling routing and data operations.
* **Easy Deployment:** Configured with `requirements.txt` and `packages.txt` for seamless cloud or local deployment.

## Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/CMRIXULAB/Chemical-Inventory.git
cd Chemical-Inventory

```


2. Install dependencies:
```bash
pip install -r requirements.txt

```


3. Run the application:
```bash
python app.py

```
